DemoBlaze Automation Testing

This project is an automation testing practice for the DemoBlaze
 website.
 
It was created for learning how to automate website testing using Selenium.

How to Run

1.Clone the repository 

`git clone https://github.com/Ziad-Sherif/DemoBlaze.git`

2.Open the project in your IDE (e.g. IntelliJ or Eclipse).

3.Make sure you have Java and Maven installed.

4.Run the tests with:

`mvn test`



Tools & Technologies

● Java

● Selenium WebDriver

● TestNG (or JUnit)

● Maven
